Reference

Click ▶ to hear the Dutch pronunciation. jij, zij, wij are used for emphasis; in everyday speech use je, ze, we.

Rules — present tense
  1. Find the base of the verb: remove -en / -n from the infinitive.
  2. ik → base  ·  jij/u/hij/zij/het → base + t  ·  wij/jullie/zij → infinitive.
Spelling of the base
  1. One consonant before -en? Double the vowel: wonen → woon, maken → maak. Exceptions: komen → kom, wandelen → wandel, luisteren → luister, winkelen → winkel.
  2. A Dutch word never ends in a double letter — drop one: kennen → ken, spellen → spel, missen → mis.
  3. Base ends in t? The singular is the same for all persons: zitten → zit — ik zit, je zit, hij zit.
  4. A verb can never end in z or v: z → s, v → f. verhuizen → verhuis, geven → geef, leven → leef.
  5. With oe, eu, ou, ie, ui, ei rule 1 does not apply: proeven → proef, houden → houd, zien → zie.
